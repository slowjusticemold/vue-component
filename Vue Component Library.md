## 🛠 Feature Breakdown

### Feature 1 — Composition API
Write components with `ref`, `reactive`, `computed`, and `watch` in a single `<script setup>` block.

### Feature 2 — Props & Emits
Define typed props with `defineProps` and emits with `defineEmits` for a clean component contract.

### Feature 3 — Slots
Build flexible components with default, named, and scoped slots.

### Feature 4 — Composables
Extract shared logic into reusable `useX()` functions.

### Feature 5 — Provide / Inject
Share state across a component tree without prop drilling.

### Feature 6 — Testing
Write unit tests with Vitest and Vue Test Utils.

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Props not updating** | Use `toRefs` or `props.x` |
| **Emits not firing** | Check event name case |
| **Slot not rendering** | Verify `<slot name="...">` |
| **Composable re-runs** | Wrap in `watchEffect` |
| **Inject undefined** | Check provide tree |
| **Test fails** | Mount with correct props |
